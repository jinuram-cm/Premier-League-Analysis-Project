# Premier League 2020/21 - Player Performance Analysis

A data analysis project exploring player and team performance in the English Premier League 2020/21 season using Python, Pandas and Seaborn.

## Analysis covered

- Top 10 goal scorers
- Top 10 assist leaders
- Most aggressive teams (yellow and red cards)
- Most aggressive nationalities
- Top goal-scoring defenders
- Most accurate passers (midfielders and forwards)

## Tools used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

English Premier League 2020/21 player statistics from Kaggle. The dataset file is included in this repository.



## How to run

1. Clone the repository:
   ```
   git clone https://github.com/jinuram-cm/Premier-League-Analysis-Project.git
   ```
2. Install the libraries:
   ```
   pip install pandas matplotlib seaborn jupyter
   ```
3. Open the notebook:
   ```
   jupyter notebook
   ```
4. Run all cells.
